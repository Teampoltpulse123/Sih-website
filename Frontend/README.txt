GEO FRAME V3
============

Topic:
Real-Time National Land Acquisition & Management System for End-to-End Digital Monitoring and Decision Support

NEW IN V3
---------
- All 28 Indian states + 8 Union Territories
- State/UT coverage dashboard and filters
- More realistic national project dataset (15+ projects)
- Open Project button with full Project Profile page
- Project milestones, packages, team and risk score
- More roles: National Administrator, State Land Officer, District Land Officer,
  SDM, Revenue Officer, Survey Officer, GIS Analyst, Legal Officer,
  Compensation Officer, Project Director, Document Reviewer,
  Citizen Support Officer, Finance Auditor, Compliance Officer, Field Inspector
- GIS Command Map with project/parcel/risk/state layers
- Land parcel profile with 8-stage acquisition lifecycle
- Project creation form
- Land parcel creation form
- Document upload form
- Field survey form
- Compensation form
- Grievance/hearing form
- User/role creation form
- Citizen status search
- AI-style priority queue
- Audit trail export
- CSV export
- Responsive mobile interface
- ALL application JavaScript is inside index.html (no app.js)
